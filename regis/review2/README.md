Review-2 deliverables and templates

This folder contains helper artifacts for Review-2 (upload / presentation / report).

Files:
- `report_skeleton.md` — project report skeleton following the BCSE497J template.
- `report_checklist.md` — actionable checklist of items to complete before submission.
- `ppt_outline.md` — slide-by-slide outline; Slide 2 reserved for guide approval.
- `attendance_sheet.csv` — simple attendance sheet template (CSV).
- `gantt_placeholder.txt` — instructions and a small ASCII Gantt placeholder.

Usage:
1. Fill `report_skeleton.md` with your project content, following the sections.
2. Prepare the PPT using `ppt_outline.md` and include the guide approval on Slide 2.
3. Save the attendance sheet as a CSV (or open in Excel) and collect signatures at Review-2.
4. Export a Gantt chart (image) and include it in the report under Project Plan.

When you're ready I can also:
- generate a starter PPTX with placeholders (requires python-pptx), or
- convert `report_skeleton.md` to a `.docx` using pandoc if you want the Word template filled.
